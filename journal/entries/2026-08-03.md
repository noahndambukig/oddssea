# 2026-08-03

## 12:55 — decision — Journal system adopted from canyoubeatchess

**What happened:** Ported the journal system from the chess project: the
`journal/` tree with its append-only rules and entry types, the `/log` skill
in `.claude/skills/log/`, and the auto-log triggers plus notification line in
`CLAUDE.md`. References adapted to this project — the authoritative-numbers
home is `docs/02-economy/currency-model.md`, and simulation results replace
training-run measurements as the main source of findings.

Other chess conventions were surveyed at the same time and deliberately
deferred, not rejected: build-order dependency tags and exit criteria, a
seams section, work packages, a primer, a risks register with stable IDs,
`implemented-by` frontmatter, and a `tools/` directory. The reason for
deferring: the design is still being fleshed out, and several of those
conventions (work packages, `implemented-by`, `tools/`) only pay off once
code exists.

**Why it matters:** Everything before today survives only in git history and
`docs/decisions/` — the texture of how the cosmetic system was designed is
already partly lost. From here, the raw material for the eventual paper or
blog post accumulates as it happens instead of being reconstructed later.
