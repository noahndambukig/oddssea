# The Dex

## Two dexes, not one combination grid

The trap to avoid: 66 garments × 66 skins is thousands of pairings, and a dex nobody can finish is a dex nobody engages with.

- **Gear Dex** — six pages, one per slot. 66 entries.
- **Skin Dex** — one page per family. 66 entries.
- **Set Tracker** — a separate view showing progress toward each themed set.

Completion stays achievable at 132 entries. Bragging stays unbounded, because specific pairings get displayed in the Closet instead — see `flex-layer.md`.

## Silhouettes for undiscovered entries

Every unowned entry shows as a filled silhouette **with its tier colour visible**. Seeing the shape and rarity of what you are missing is dramatically more motivating than a blank slot — it converts an abstract gap into a specific want.

## Variants over volume

Each entry can hold sub-variants, shown as small pips on the dex tile. Variants are recolours and parameter changes, not new art, so they multiply dex depth for almost nothing:

| Variant | Description | Availability |
|---|---|---|
| **Seasonal** | The same skin in a winter or festival palette | Event window only |
| **Prismatic** | A rare shiny-style treatment with an unmistakable shimmer | ~1 in 400 drops |
| **Corrupted** | A glitched, inverted treatment | Event only |

Pokémon has sustained decades of chase on shinies, which are functionally a palette swap. Variants are the highest-leverage mechanic in this entire design.

## First-discovery credit

Where discovery is possible — fusion outcomes, hidden variant conditions — **the first player to find it is permanently credited on the dex entry**, visible to everyone. This is the strongest flex available anywhere in the system because it cannot be bought, traded or repeated, and it reliably generates community wikis and theorycrafting.

Award a Mythic to the first player to complete each season's full set. Not a Mythic *drop* — a specific, named, one-of-one item.
