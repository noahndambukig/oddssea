# Identity

**Name:** oddssea — *odds* + *sea*, read aloud as *odyssey*. The name is
the design in two syllables: a gambling game (odds) with a nautical skin
(sea) framed as a long voyage (odyssey).

**Icon: a sailboat.** It carries both halves of the pun at once — the
odyssey's voyage and the sea the odds sail on — and a boat silhouette
stays legible at favicon size, the same silhouette-first legibility rule
the cosmetics live by (`../00-project/pillars.md`, pillar 2).

Where it applies: the favicon, the PWA manifest icon
(`../04-technical/platform.md`), and eventually the store listing icon.
One mark everywhere — the icon should not fork per surface.

Adjacent identity already settled elsewhere: the currencies are Shells
and Pearls (`../decisions/0005-wagering-earns-the-cosmetic-currency.md`),
the flagship game is sea races (`../decisions/0007-seven-game-launch-roster.md`),
and the top cosmetic is Void Weave — the nautical-cosmic register is the
brand, and the sailboat is its simplest possible expression.
