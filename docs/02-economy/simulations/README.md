# Simulations

Any figure in `../currency-model.md` that came from a simulation is reproducible here. If you change a price, re-run these before updating the doc.

| Script | Answers |
|---|---|
| `set-completion.py` | How many Set Crates to finish a six-piece set, and how many days that is for each player profile |
| `crate-rates.py` | Effective drop rates once pity timers are applied |
