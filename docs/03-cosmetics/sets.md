# Sets

**A set is a skin family spanning all six slots.** "Void Weave" exists as a headgear skin, a shirt skin, a pants skin and so on. Completing the set means owning all six.

This structure does three useful things at once:

1. It **preserves gear as an independent axis** — you wear the set on whatever garments you like.
2. It means **two players in the same set still look different**, because their underlying garments differ. Personal expression survives set-chasing.
3. It **pulls purchases across all six slots**, including the unloved ones. Someone who bought the cap skin because it looked good now has five more purchases queued, and the last one is the one they will grind for.

## Composition

Each set mixes tiers deliberately: **five Common-to-Epic pieces plus one Legendary keystone.** The set is achievable, but the keystone is the wall — and the wall is where the top-end sink lives.

Launch sets are designated in `content/skin-roster.md`; post-v1 seasonal
set concepts are in `content/set-list.md`.

## Set bonuses

Partial bonuses matter. A player at 3/6 with no reward is a player who abandons the set.

| Progress | Reward |
|---|---|
| **3 / 6** | Nameplate tint in the set's palette |
| **5 / 6** | Unique idle pose |
| **6 / 6** | Full-body aura FX · a title · a mannequin pedestal in the Closet · a one-time Shell bonus |

**The completion bonus is one-time, paid in Shells — never a recurring stipend** — see `decisions/0005`. The bonus amount lives in `02-economy/currency-model.md`. Ongoing veteran rewards are deferred, not rejected.

## Test the full-set look early

Whichever skin family you pick as a Legendary exists across all six slots, so players will wear it as a complete outfit. Six overlapping animated materials is a very different image from one. Verify it reads before committing to the effect.
