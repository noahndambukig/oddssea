# Asset Budget

Based on the launch roster of 11 gear and 11 skin families per slot.

| Item | Count |
|---|---|
| Garments (6 slots × 11) | 66 |
| Garment asset files (base + mask each) | 132 |
| Shared pattern textures | ~16 |
| Master animated material | 1 |
| Legendary / Epic FX parameter sets | ~8 |
| **Total hand-authored assets** | **~157** |

## What it produces

| | |
|---|---|
| Distinct looks per slot | 121 |
| Total slot-looks | 726 |
| Outfit permutations | ~3.1 trillion |
| Dex entries | 132 |

## Time

At 2–4 hours per garment, launch gear is **130–260 art hours** — a realistic small-team scope, though the upper end is most of a quarter for a single artist.

## The lever if that's too much

Cut gear per slot, not slots. Going from 11 to 8 garments per slot drops you to 48 garments and ~100 asset files, roughly a third less work, while keeping all six slots — and six slots is what makes the set system work. Cutting a slot instead would break sets and cost you a sixth of the flex surface.

Trim from the Commons. Five Commons per slot is generous; three is survivable at launch and the other two become your first content drop.
