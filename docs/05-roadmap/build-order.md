# Build Order

| Phase | Scope |
|---|---|
| **1 — MVP** | Six slots · grayscale+mask pipeline · 5 tiers · Gear and Skin crates with pity · both dexes with silhouettes · **static and material tiers only, no motion** · 3 sets · basic profile display |
| **2 — Depth** | Animated Epic and Legendary shaders · set bonuses · the Closet with visits · loadout presets · dust salvage · remaining sets |
| **3 — Economy** | Fusion · variants (prismatic, seasonal) · Mythic events and first-discovery credit · combined-rarity readout · tipping · marketplace with burn |
| **4 — Long tail** | Wear/condition axis · seasonal rotation cadence · additional body silhouettes · turnaround and idle animation |

## Why Phase 1 has no motion at all

Shipping the MVP entirely static is deliberate. It proves the pipeline, the dex and the economy with the cheapest possible art, and it means the arrival of animated Legendaries in Phase 2 is a **launch moment** rather than a detail nobody notices.

It also de-risks the most expensive unknown. If the mask-channel pipeline has problems, you find out while the only cost is recolouring flat shapes.
